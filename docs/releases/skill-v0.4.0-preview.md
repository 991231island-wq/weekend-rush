# Weekend Rush Skill v0.4.0-preview

发布范围：可安装的AI客户端Skill及查询、校验、行程卡脚本。网页AI应用不属于本次上线范围。预览标签表示尚未完成外部用户试用，不能据此声称已验证用户价值。

## 用户能做什么

- 说出周末旅行意向，让助手主动推荐并安排两天一晚的吃、住、玩、公共交通和休息。
- 查询12306 G/D直达车次，高德地点、周边、公交/步行指引及预报日期内天气。
- 一句话提出少走路、换地点、晚出发等调整，更新受影响路线并保护已完成事项。
- 查看预算、时间、预约与未知信息；预算不足仍输出完整参考行程，不自动改变预算上限。
- 导出本地HTML行程卡；卡片调整按钮复制请求，实际修改发生在AI客户端。

## 安装与依赖

资产 `weekend-rush-skill-v0.4.0-preview.zip` 解压后为单个 `weekend-rush/` 文件夹。需要Node.js 22+，每位使用者自行配置高德Web服务Key。模型使用宿主客户端，不要求额外模型Key。详见 [安装说明](../install-skill.md)。

固定顶层依赖：12306 MCP 0.3.10、高德MCP 0.0.8、MCP SDK 1.32.1；锁文件随包分发。原创代码MIT，第三方许可声明随包保留。

## 已知边界

餐饮实际价格、酒店日期化报价、门票和日期化营业的独立接入口已保留但默认没有连接来源。高德消费和营业文本只作参考；房价、房态、预约名额不能由POI存在推断。官方网页补查依赖宿主浏览能力，不能承诺自动覆盖所有场馆。

首版聚焦已确定目的城市的两天一晚、单人公共交通，铁路为G/D直达候选。不购票、不订房，不做多城、多人协商或自驾/骑行。当前无已发布的独立AI网页；仓库中的网页源码仍属于开发/联调部分。

本次发布不提供共享高德Key。余票、价格、路线及天气均为查询时信息，采用前复核。
