# 本机真实数据版 v0.2.0 预览

此文档取代 v0.3 进度中“网页仅为固定样例”的状态说明。GitHub 和魔搭尚未发布。

## 启动与操作

Node.js 22+，本机已配置高德 Web 服务 `AMAP_MAPS_API_KEY` 后，在仓库执行 `npm ci --ignore-scripts --no-audit --no-fund`，然后 `npm start`，访问 http://127.0.0.1:4173 。不应将 Key 输入网页或提交到仓库。

1. 读取真实车站，确认杭州东 HGH 与上海虹桥 AOH；选当天起 15 天内相邻两天。
2. 查询往返车次，手动选择查询时有票且有价格的席别。展开明细核对车站、完整日期、价格、无票与候补状态及查询时间。
3. 搜索“上海虹桥站”，选择类型 150200 的火车站主体；不能用地铁站或出入口代替。
4. 选择一个具体住宿参考点，例如明确分店的酒店。金额仍为自己填写的预留，并非查询房价或已订房。
5. 搜索“外滩”等地点，核对地址、POI ID 和类型后选择。可加人民广场等可选点；门票留空必须显示未知。
6. 生成两套方案，对照路线步行、活动时间和待确认项。预算改为 100 元或最晚到家改早，重新生成应显示冲突；点击上一轮结果应能查看旧方案。

真实页面没有固定样例回退。接口失败会报错或产生无法生成的方案；原离线原型保留在 `/demo`，其中所有数据仍是模拟值。

## 数据边界

| 数据 | 当前依据 |
| --- | --- |
| 车站、车次、席别、票价、查询时余票 | 12306 MCP；按精确电报码过滤，乘车日加时刻与历时构造到达日期 |
| 地点与坐标 | 高德搜索后人工选择，再用详情核对城市；同名候选不自动采用第一条 |
| 市内路线时间和步行 | 高德步行/公交返回；秒转分钟，保留查询时间；不代表未来实际班次和拥堵 |
| 天气 | 仅使用工具返回中与出行日相符的预报 |
| 餐饮、住宿、市内交通与门票预留 | 用户估算；高德 MCP 当前未提供公交票价，未查酒店房价 |
| 住所接驳、景区内部步行、开放和预约 | 未完整查询；明确待确认，不能宣布所有约束已满足 |

网页为真实工具数据加规则排程，没有连接大模型。支持行前修改条件重新计算，最近三轮结果保存在页面内存；途中基于当前位置和已完成活动的重排尚未接入真实网页。

- 联调的完整来源、查询时间、输入和验证结果保存在 [公开样例记录](live-query-2026-10-15.json)，历史记录不应被当作最新查询。
